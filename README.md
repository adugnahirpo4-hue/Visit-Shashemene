# 🌍 Visit Shashemene — Culture & Tourism Adventure Website

**Discover Shashemene. Explore Its Culture. Experience Its Beauty.**

Visit Shashemene is a culture and tourism website designed to showcase the attractions, history, cultural diversity, people, and natural beauty of Shashemene, Ethiopia. The project aims to help tourists, residents, and other interested visitors discover the city's unique identity, explore interesting destinations, and learn more about local life.

## 📖 About the Project

Shashemene is a vibrant city in the Oromia Region of Ethiopia, known for its cultural diversity, commercial activities, and the presence of the Rastafari community.

The **Visit Shashemene** project provides an online platform for discovering the city's attractions, cultural heritage, natural environments, hotels, public institutions, and other places of interest.

The website is built using HTML, CSS, and JavaScript, with EmailJS integration to allow visitors to send inquiries and messages directly to the website owner's email.

## ✨ Features

* 🏠 **Home:** An engaging landing page introducing Shashemene and its unique identity.
* 🖼️ **packages :** A visual collection of photographs showcasing the city's attractions, scenery, and everyday life.
* 📍Location&#x73;**:** Information about historical, cultural, natural, and recreational destinations.
* 🏛️ **Public Institutions:** Information about selected city administration offices and public services.
* 🌍 **Culture & People:** An introduction to Shashemene's cultural diversity, traditions, communities, and way of life.
* 🏨 **Hotels & Hospitality:** Information about selected hotels and places to stay or enjoy local meals.
* 🌳 **Natural Attractions:** Highlights of natural destinations, including Sole Natural Forest.
* 📱 **Responsive Design:** A website designed to adapt to different screen sizes, including desktop computers, tablets, and mobile phones.
* 📧 **Contact Form:** EmailJS integration that allows visitors to submit inquiries and messages directly to the configured email address.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need:

* A modern web browser, such as Google Chrome or Microsoft Edge.
* A code editor, such as Visual Studio Code.
* Git, if you want to clone the repository.

### Installation

**1. Clone the Design**

**2. Navigate to the project directory**

```bash
cd Visit-Shashemene
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code for a convenient local development experience.

### EmailJS Configuration

To enable the contact form:

1. Create an account on [EmailJS](https://www.emailjs.com/).
2. Configure an email service.
3. Create an email template with the variables required by your form.
4. Add your EmailJS service ID, template ID, and public key to the appropriate JavaScript configuration.
5. Test the contact form to confirm that messages are delivered successfully.
